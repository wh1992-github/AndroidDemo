# OpenSpec Instructions

These instructions are for AI assistants working in this project.

Before planning, proposing new capabilities, or handling breaking changes, read the project's actual spec files in this directory:
- `config.yaml` — schema (`spec-driven`) and per-artifact rules
- `project.md` — project context, tech stack, module map, conventions
- `feature-summary.md` — feature index (class names are indicative; source code is authoritative)
- `specs/` — current specifications
- `changes/` — change proposals, designs, tasks, and archives

Note: the OpenSpec default `@/openspec/AGENTS.md` does not exist in this project. Use the files above instead.

When a request is ambiguous or needs spec clarification, ask the user rather than assuming.
